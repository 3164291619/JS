数据类型简介

什么是数据类型

数据类型简而言之就是数据的类别型号

变量的数据类型

变量用来储存值的所在地，他们有名字和数据类型。JavaScript是一种弱类型或者说动画语言

数据类型的分类

简单数据类型
简单数据类型 说明 默认值
Number 数字型，包含整型值和浮点型，如1.22、1 0
Boolean 布尔值型，如true、false，等价于1和0 false
String 字符串型，如“张三”，注意js里面字符都要加“” “”
Undefined var a;声明变量a，但没有给值时，a=Undefined Undefined
Null var a=null,声明变量a为空值 Null
注意小细节
数字型进制，常见的有二进制、八进制、十进制、十六进制
数字范围，js中数值的最大值和最小值
数字型三个特殊值：infinity无穷大；-infinity无穷小；NaN,Not a number,代表一个非数值
